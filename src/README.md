**Deployment Platform:** Render

### Project Overview
The network quality evaluation platform that uses the IETF Quality of Outcome (QoO) framework to evaluate network conditions against application-specific requirements.

### Key Features
- Two configurable application profiles.
- Six controlled network impairment scenarios.
- Automated QoO experiment execution.
- Network latency, throughput, jitter and packet loss measurement.
- Application-level metric collection.
- Comparative analysis of application profiles.
- Interactive results dashboard.
- Experiment history and CSV/JSON data export.
