Controlled Impairment Scenarios

Six standardized network impairment scenarios applied through Linux tc-netem on the gateway container.

S1: Baseline Network Clean Line

Ideal pristine optical/LAN connection with zero intentional impairments.

0ms delay • 0ms jitter • 0.0% loss
S2: High Delay Latency Bound

Cross-continental fiber or geostationary satellite hops with fixed high propagation delay.

150ms delay • 0ms jitter • 0.0% loss
S3: High Jitter Delay Variance

Congested cellular LTE or multi-hop Wi-Fi with high packet arrival variance.

50ms delay • 30ms jitter • 0.0% loss
S4: Packet Loss Random Drops

Moderate packet drop rate triggering TCP congestion window collapse and retransmissions.

0ms delay • 0ms jitter • 1.5% loss
S5: Combined Delay + Jitter Queuing Impairment

Compound delay and delay variance isolating bufferbloat without packet drops.

100ms delay • 25ms jitter • 0.0% loss
S6: All Combined (Dirty WAN) Severe WAN

Simultaneous delay, jitter, and loss typical of degraded mobile or satellite links.

100ms delay • 20ms jitter • 2.0% loss
